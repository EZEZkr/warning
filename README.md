# 큐브 부정활동 경고 생성기

큐브(QUBE) 운영 담당자가 부정활동 회원에게 보내는 경고·제재 안내 쪽지를 빠르고 일관되게 작성하도록 돕는 웹 도구입니다.

## 왜 만들었나

- 부정활동 모니터링 후 유형에 맞는 문구를 직접 찾아서 쓰다 보니 시간이 오래 걸리고, 담당자마다 문구가 조금씩 달라졌습니다.

## 주요 기능

- **위반 유형별 문구 생성**: 위반 유형, 대상(마스터·학생), 제재 단계를 고르면 해당 안내 문구를 만들어 줍니다.
- **추가 문단 선택**: 정지 조치, 포인트 회수 안내 등 필요한 문단만 골라 붙일 수 있습니다.
- **입력값 강조 미리보기**: 이름, 날짜, 금액처럼 직접 입력한 부분을 미리보기에서 강조해 발송 전에 확인하기 쉽게 했습니다.
- **개인정보 보호**: 학생 이름은 가운데 글자를 가려(예: 홍*동) 표시합니다.
- **원클릭 복사**: 완성된 문구를 버튼 하나로 복사할 수 있습니다.

## 운영 원칙

- 이 도구는 문구 작성만 돕습니다. **발송은 자동화하지 않고, 담당자가 내용을 확인한 뒤 직접 보냅니다.**
- 회원 정보는 저장하거나 외부로 전송하지 않습니다. 모든 처리는 사용자의 브라우저 안에서만 이뤄집니다.

## 사용 방법

1. 배포된 페이지에 접속하거나 `index.html`을 브라우저로 엽니다.
2. 위반 유형과 대상을 고르고, 필요한 정보를 입력합니다.
3. 생성 버튼을 누르고 미리보기에서 강조된 부분을 확인합니다.
4. 복사 버튼으로 문구를 복사해 발송합니다.
